- `20261028110000_game_checkpoint_rpc.sql`：拒絕舊序號覆蓋新 checkpoint，並拒絕同序號不同內容。
- `20261028113000_shop_config.sql`：建立唯讀商城設定資料表及商品目錄。
- `20261028120000_finish_game_chapter_rpc.sql`：章節完成事件去重、工具扣除、永久進度更新及符合條件的生命退還。
- `20261028121500_security_events_and_account_lock.sql`：安全事件與伺服器端帳號鎖定 RPC。

### Edge Functions
- `account-snapshot`：讀取會員、Gold、生命及工具；嘗試執行每日 Gold 領取與生命恢復。
- `start-game-session`：檢查請求格式與初始棋盤，呼叫原子新局 RPC。
- `save-game-checkpoint`：驗證快照大小並儲存序號遞增的快照。
- `finish-game-chapter`：使用移植的 replay validator 核對初始棋盤及操作紀錄，成功後才呼叫結算 RPC；重播或工具庫存驗證失敗會記錄安全事件並鎖定帳號，保留客服入口。
- `supabase/functions/_shared/replay_validator.js`：從既有 Firebase 後端移植 replay validator。
- `supabase/functions/_shared/replay_validator_test.ts`：新增初始棋盤、未完成過關、事件數上限及章節工具權限測試。

### Flutter 遷移
- 新增 Supabase SDK、初始化封裝、帳號快照 client、遊戲 session/checkpoint/過關 client。
- `main.dart` 支援用公開 URL/key 選擇性初始化 Supabase，但仍保留 Firebase 啟動，避免尚未遷移的服務中斷。
