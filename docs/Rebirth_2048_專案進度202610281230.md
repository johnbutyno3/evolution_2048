### Supabase 資料庫與權限
- 初始 schema：會員、Gold、工具庫存、生命、每日 Gold、章節進度、遊戲 session、購買交易、客服與通知。
- RLS 權限及 profile 欄位限制，防止使用者自行修改帳號鎖定狀態。
- Gold／工具原子帳務 RPC、生命扣除／退還 RPC、伺服器時間生命恢復 RPC、依帳號時區每日 Gold 領取 RPC。
- 遊戲 session 新局 RPC：請求去重、同一使用者只允許一個 ACTIVE session、FREE 新局扣命與建立 session 在同一資料庫交易中完成，並將初始棋盤綁定至 session。
- 棋盤 checkpoint RPC：拒絕舊序號覆蓋新快照，拒絕同序號不同內容。
- 章節完成 RPC：交易去重、工具庫存結算、永久章節進度更新及 FREE 生命退還。
- 安全事件表與伺服器端帳號鎖定 RPC。

### Supabase Edge Functions
- `account-snapshot`：登入後讀取權威會員、Gold、生命、工具數量；啟動時嘗試依伺服器時間恢復生命及領取每日 Gold，兩者均以資料庫函式去重。
- `start-game-session`：驗證使用者、UUID、章節與初始棋盤，呼叫原子新局 RPC。
- `save-game-checkpoint`：驗證棋盤快照大小及序號。
- `finish-game-chapter`：移植既有 replay validator，先驗證完整操作紀錄與初始棋盤，再呼叫伺服器端結算。重播驗證失敗或工具使用／庫存不一致時，記錄安全事件並鎖定帳號；回應保留客服管道。

### Flutter 遷移
- `pubspec.yaml` 加入 `supabase_flutter: ^2.9.0`。
- 新增 `SupabaseBackend` 初始化封裝、帳號快照 client、遊戲 session／checkpoint／過關 client。
- `main.dart` 開始支援透過 `SUPABASE_URL`、`SUPABASE_PUBLISHABLE_KEY`（或 `SUPABASE_ANON_KEY`）選擇性初始化 Supabase。
- `ShopConfigService` 已改為從 Supabase 的唯讀 `shop_config` 表讀取設定，未設定或服務失敗時使用既有本機預設值。
- Firebase 登入與其他服務尚未全部遷移，因此 Firebase 依賴目前保留；不能提前移除。
