# Rebirth 2048 — Game Rules

## 1. 核心遊戲規則

- 棋盤固定為 4×4。
- 電腦測試使用方向鍵 ↑ ↓ ← →。
- 手機正式操作使用觸控滑動。
- 相同生命階級可以合成為下一階。
- 遊戲核心仍遵循 2048 的移動與合成規則。
- 道具只能輔助玩法，不得直接跳過核心合成。

---

## 2. 六章架構

| 章節 | 篇章 | 通關階數 | 道具種類 | 每種道具使用次數 | 通關結果 |
|---|---|---:|---:|---:|---|
| 第1章 | 海洋篇 | 12階 | 1種 | 1次 | 過場 → 第2章 |
| 第2章 | 陸地篇 | 13階 | 1種 | 1次 | 過場 → 第3章 |
| 第3章 | 天空篇 | 14階 | 2種 | 各1次 | 過場 → 第4章 |

| 第5章 | 科技篇 | 16階 | 4種 | 各1次 | 過場 → 第6章 |
| 第6章 | 宇宙篇 | 17階 | 禁用 | — | 終極挑戰 |

## 3. 道具配置

道具隨章節逐步增加，但不讓高階道具破壞遊戲平衡：

- 第1章：Revive
- 第2章：Revive
- 第3章：Revive + Time Rewind
- 第4章：Revive + Time Rewind + Position Swap
- 第5章：Revive + Time Rewind + Position Swap + Duplicate
- 第6章：全部禁用

### Revive

- 移除玩家指定的一個 Tile，立即產生一個空格。
- 第1～5章可使用。
- 每局每章限用1次。
- Game Over 後仍可使用，作為救援工具。

### Time Rewind

- 回復最近一次有效移動前的棋盤。
- 第3～5章可使用。
- 每局每章限用1次。
- Game Over 後仍可使用，只要仍保留上一個有效狀態。

### Position Swap

- 第4～5章使用。
- 玩家依序選擇兩個已存在的 Tile。
- 兩個 Tile 只交換位置，不改變階級與數值。
- 每局每章限用1次。

### Duplicate

- 第5章限定。
- 將指定 Tile 複製到一個空格。
- 為避免直接複製高階物種而破壞難度，**只能複製 256 以下的 Tile**。
- 512、1024、2048 及以上階級不可複製。
- 每局每章限用1次。

---

## 4. 工具設計原則

工具的目的，是讓玩家在卡關時有一次策略救援，而不是讓玩家直接取得高階物種。

因此：

- Revive 是主要救援工具，第一章就提供。
- Time Rewind 用於修正一次錯誤移動。
- Position Swap 用於重新整理棋盤結構。
- Duplicate 僅能複製低階 Tile，不能直接複製高階 Tile。
- 工具不能直接完成章節。
- 第6章完全禁用工具，保留最終挑戰難度。

---

## 5. Game Over 與工具

Game Over 的條件仍然是：

1. 4×4 棋盤已滿。
2. 沒有任何相鄰的相同 Tile 可以合成。
3. 尚未達成該章節的目標階級。

Game Over 出現後：

- 玩家可以重新開始。
- 玩家也可以關閉 Game Over 視窗，使用尚未使用的救援工具。
- 使用 Revive、Time Rewind、Position Swap 或合法的 Duplicate 後，若棋盤重新恢復可行狀態，遊戲繼續。

---

## 6. 章節完成流程

達成指定階數後：

```text
達成指定階數
      ↓
章節完成
      ↓
播放章節完成畫面
      ↓
下一章解鎖
      ↓
直接進入下一章
```

第6章完成後為全遊戲終極挑戰完成。
