# Rebirth 2048 — Game Rules

## 1. 核心遊戲規則

- 棋盤固定為 4×4。
- 電腦測試使用方向鍵 ↑ ↓ ← →。
- 手機正式操作使用觸控滑動。
- 相同生命階級可以合成為下一階。
- 遊戲核心仍遵循 2048 的移動與合成規則。
- 道具只能輔助玩法，不得直接跳過核心合成。

---

## 2. 六章架構

| 章節 | 篇章 | 通關階數 | 道具種類 | 每種道具使用次數 | 通關結果 |
|---|---|---:|---:|---:|---|
| 第1章 | 海洋篇 | 12階 | 1種 | 1次 | 過場 → 第2章 |
| 第2章 | 陸地篇 | 13階 | 2種 | 1次 | 過場 → 第3章 |
| 第3章 | 天空篇 | 14階 | 3種 | 1次 | 過場 → 第4章 |
| 第4章 | 歷史篇 | 15階 | 4種 | 1次 | 過場 → 第5章 |
| 第5章 | 科技篇 | 16階 | 4種 | 1次 | 過場 → 第6章 |
| 第6章 | 宇宙篇 | 17階 | 1種（僅UNDO） | 1次 | 終極挑戰 |

## 3. 道具配置

道具依章節逐步增加，最終配置如下：

| 道具 | 第1章 | 第2章 | 第3章 | 第4章 | 第5章 | 第6章 |
|---|---|---|---|---|---|---|
| UNDO | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| REMOVE | — | ✓ | ✓ | ✓ | ✓ | — |
| SWAP | — | — | ✓ | ✓ | ✓ | — |
| DUPLICATE | — | — | — | ✓ | ✓ | — |

### UNDO

- 回復最近一次有效移動前的棋盤。
- 第1～6章皆可使用。
- 每局每章限用1次。
- 只有在存在上一個有效移動狀態時才可執行。

### REMOVE

- 移除玩家指定的一個 Tile，立即產生一個空格。
- 第2～5章可使用。
- 每局每章限用1次。

### SWAP

- 第3～5章可使用。
- 玩家依序選擇兩個已存在的 Tile。
- 兩個 Tile 只交換位置，不改變階級與數值。
- 每局每章限用1次。

### DUPLICATE

- 第4～5章可使用。
- 將指定 Tile 複製到一個空格。
- **不限制 Tile 階數或數值。**
- 每局每章限用1次。

---

## 4. 工具設計原則

工具的目的，是讓玩家在卡關時有一次策略救援，而不是直接完成章節。

因此：

- UNDO 是全六章皆可使用的基礎工具。
- REMOVE 從第2章開始提供，至第5章可用。
- SWAP 從第3章開始提供，至第5章可用。
- DUPLICATE 從第4章開始提供，至第5章可用，且不限制複製階數。
- 第6章只保留 UNDO，其他工具禁用。
- 工具不能直接完成章節。

---

## 5. Game Over 與工具

Game Over 的條件仍然是：

1. 4×4 棋盤已滿。
2. 沒有任何相鄰的相同 Tile 可以合成。
3. 尚未達成該章節的目標階級。

Game Over 出現後：

- 玩家可以重新開始。
- 玩家也可以關閉 Game Over 視窗，使用尚未使用的救援工具。
- 使用 UNDO、REMOVE、SWAP 或合法的 DUPLICATE 後，若棋盤重新恢復可行狀態，遊戲繼續。

---

## 6. 章節完成流程

達成指定階數後：

```text
達成指定階數
      ↓
章節完成
      ↓
播放章節完成畫面
      ↓
下一章解鎖
      ↓
直接進入下一章
```

第6章完成後為全遊戲終極挑戰完成。
