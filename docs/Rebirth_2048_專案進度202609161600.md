## Security Enforcement Layer
建立：`functions/security_enforcement.js`

相關 commits：
- `628b847e77cdcaa25c6826452530b10dfaf3a1f7` — add centralized server enforcement gate
- `ac0090bd` — enforcement reads cumulative `riskScoreTotal` to determine CRITICAL
- `5aa7575` — client access to `security_enforcement/{uid}` locked by Firestore rules

用途：建立單一 server-side sensitive-operation enforcement layer，避免未來在各 callable 中建立多套風險封鎖邏輯。

目前支援的敏感操作識別：
- purchase_tool
- use_tool
- spend_gold
- start_game_session
- complete_chapter
- purchase
- grant_membership

目前規則：
- NORMAL：允許
- WARNING：允許
- ADMIN_ALERT：允許，但持續由 Security Audit / Admin Notification 監控
- CRITICAL：敏感操作拒絕
- 已存在有效 restriction：敏感操作拒絕

限制狀態由 server-only `security_enforcement/{uid}` 管理；client 不應直接寫入。
`applyCriticalRestriction()` 預設限制 24 小時，最長 30 天。
