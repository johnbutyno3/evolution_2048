## 固定權威規則

1. 棋盤、合併、動畫、音效等普通遊戲互動本機即時處理，不等待 Firebase。
2. Gold、購買／交易、會員資格及權限屬重要權威驗證；伺服器確認符合既定重大異常條件時，才依安全政策限制／鎖定帳號並記錄稽核證據。
3. 玩家對重要驗證結果的異議走既有雙方留言／問題回報流程，與交易權威判定分開。
4. 其他一般資料差異，在後端成功回傳有效完整的權威資料後，以後端資料為準修正本機；一般差異本身不直接鎖定帳號。
5. 網路逾時、App Check 服務錯誤或 Firebase 暫時失效，不得直接判定作弊或當作有效權威結果。
6. Life、Game Session、購買等具有副作用的命令必須具備伺服器防重與逾時恢復策略。

## 程式碼審查初步發現（尚未修改／尚未測試）

- `functions/index.js` 使用 Cloud Functions v2 global `enforceAppCheck: true`，敏感 callable 已有伺服器端檢查。
