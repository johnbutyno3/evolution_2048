## Rules Emulator 測試範圍

新增 `cloud_backend/functions/src/firestore_rules.emulator.test.js`，透過真實 Firestore Emulator / `@firebase/rules-unit-testing` 測試：
- 未登入者不能讀寫受保護的使用者資料。
- 使用者可讀自己的 profile/progress，但不能直接寫入。
- 不可跨 UID 讀取其他使用者 profile/progress/wallet/membership/purchases。
- 遊戲 Session、RESET operation receipt、purchase transaction ledger、security events/risk/enforcement、support case/message 皆不能由客戶端直接讀寫。
- 使用者可讀取自己的 wallet、membership、purchase 狀態，但不能直接改寫。
- feedback 只能由本人建立，建立後不能由客戶端修改。
- 已登入客戶端可讀共享 config，但不能修改。

目前 Emulator 測試已隨 Cloud Backend Check 通過。這表示上述規則測試通過，不等同於已完成真實帳號的 Firebase E2E 或正式環境部署驗證。
