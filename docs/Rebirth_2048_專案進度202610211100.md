## 已確認的帳號與存檔防護

- `SaveManager` 以 UID 分開保存本機棋盤與 session ID。
- 存檔資料包含 `saveOwnerUid`；舊引擎延遲送出的快照由目前帳號所有權及 session ID 檢查拒絕。
- 舊版全域存檔不會自動歸屬任何登入帳號；只有伺服器 session ID 相符才允許遷移。
- `GameEngine` 建立時記錄存檔擁有者，避免舊引擎把快照寫入新帳號。
- 遊戲頁非同步 RESET／章節切換流程在等待後重新檢查帳號與 generation；有歧義的 RESET 保留 pending payload，避免盲目回滾。
- `PendingOperationStore` 的 key 包含 UID；登出流程會清理經濟快取並切換 SaveManager / PlayerProgressService 的帳號狀態。
- `test/session_generation_test.dart` 已覆蓋 UID 存檔隔離、舊 session 拒絕、舊資料遷移比對、經濟快取切換等情境。
