## 已有程式修改的主要範圍

- Supabase 作為新帳戶與遊戲經濟資料的後端目標；Flutter active runtime 已不再以 Firebase Flutter SDK 作為新功能後端。
- 帳戶啟動同步會員、Life、Gold、工具庫存及伺服器 active game session。
- 本機 A/B checksummed snapshots、帳戶隔離、依伺服器 active session 選擇正確快照。
- 新局生命扣除由伺服器交易執行；Resume／重新進入不重複扣除。
- Restart YES 使用原子化後端交易，延續原始 Life debit ledger reference，不額外扣 Life；取消／NO 不應呼叫 Restart RPC。
- Game Over 不額外扣 Life；完成章節後依原始 FREE Life debit 條件退還一次，並受 5 點上限約束。
- FREE Life 上限 5、每 40 分鐘恢復 1 點。
- 每日 Gold 使用裝置 IANA timezone，並以 24 小時領取紀錄防止時區切換跨日重複領取。
- 工具購買 request UUID 持久化，避免 App 重啟重試重複扣款。
- membership／purchase transaction 寫入權限限制。
- Premium → Golden 升級價 USD 3.00 的 shop config 與管理員設定串接。
