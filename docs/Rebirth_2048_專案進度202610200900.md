# Rebirth 2048 專案進度（2026-10-20 09:00）

## 本輪目標

延續 `fix/game-state-root-cause-20261019` 分支上的 Firebase 後端重構。GitHub 是本輪檢查與修改依據；未修改獨立備份倉庫，未部署 Firebase。

## 本輪已提交的修改

1. 移除 `callable_ownership.test.js` 中過時的 `refundLife` 必要匯出要求。當前 `life.js` 與 `LifeManager` 已不再提供獨立公開退款 callable。
2. 在 `callable_contract.test.js` 加入回歸檢查，確保不重新暴露 `refundLife`。通關退款應由伺服器授權的通關結算交易完成，避免使用者直接呼叫退款端點增加生命。
3. 新增 `restart_idempotency.js`：以帳號、操作 ID 產生操作文件 ID 與穩定 Session ID，並以請求內容指紋識別相同／不同參數。
4. 修改 `game_session.js` 的 `restartGameSession`：在扣除生命、替換舊 Session、建立新 Session 的同一個 Firestore transaction 中讀寫操作收據。相同 operation ID 與相同 payload 會重播原始結果；相同 operation ID 搭配不同 payload 會拒絕。
5. 修改 Flutter `PlayerProgressService.restartGameSession`：透過 `PendingOperationStore` 持久化並傳送 operation ID，讓同一個未確定結果的 RESET 重試可以使用相同 ID。
6. 新增 restart idempotency helper 單元測試，並把它納入 Functions `npm test`；在 callable contract test 中加入前後端冪等性接線檢查。
