# Rebirth 2048 專案進度 — 2026-10-20 13:20

## RESET 結果不明時的返回流程

繼續追查上一輪的 fail-closed 路徑時，發現 BACK 仍可能在 pending RESET 未解決時呼叫 `abandonGameSession` 並保存畫面快照。若 RESET 其實已在伺服器提交，這會干擾剛建立的 session；若結果仍不明，也可能覆蓋待恢復的棋盤。

已修正：

- 返回前先檢查是否仍有 RESET payload。
- 有待處理或無法讀取該記錄時，停止遊戲計時與 UI 更新計時，直接離開遊戲頁；不保存新快照、不呼叫 `abandonGameSession`。
- 之後重新進入遊戲時，再以原 operation ID 恢復並對齊後端結果。
- 新增契約測試，要求 BACK 的 pending 檢查必須先於 session abandon／保存流程。
