工作分支：`fix/game-state-root-cause-20261019`

1. **RESET 冪等性與持久化清理**
   - 後端用操作 ID、請求指紋及 Firestore transaction 收據，避免同一個 RESET 重試重複扣命。

   - 明確禁止客戶端讀寫 `users/{uid}/game_session_operations/{operationId}`，避免客戶端偽造 RESET 冪等性收據。
4. **回歸測試**
   - 擴充 callable contract 測試，鎖定購買意圖不可更換交易編號／商店 provider 的條件。
