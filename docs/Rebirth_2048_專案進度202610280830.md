### 重要安全修正
- profile 的客戶端更新權限只允許 `display_name`、`locale_code`，避免使用者自行修改 `account_status`。
- 客服案件只能關聯該使用者自己的購買紀錄。
- 會員交易撤銷不會自動等同整個帳號遭鎖定；撤銷的會員權益以 FREE 層級呈現。
- GitHub 已確認以上新增檔案可讀回。進度文件仍遵守先提交 GitHub、再上傳檔案庫的順序。
