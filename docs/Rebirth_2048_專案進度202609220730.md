# 2026-09-22 追加進度（本次接續作業）

## A. 本次核心問題

使用者要求：測試頁增加「無論哪一關，所有工具都開通」的測試功能；同時確認商城購買的工具必須真的能在遊戲中使用，否則目前無法正常通關。

檢查發現除了原先重置棋盤問題之外，工具系統還有一個實際阻斷使用的前後端契約錯誤：

- Firebase useTool 已要求 sessionId。
- Flutter ToolManager.useServer() 原本只傳 toolType，沒有傳目前的遊戲 session ID。
- 因此商城即使成功購買工具，遊戲真正使用工具時仍會被後端拒絕。
- 已在 Git 修正。

## B. 已完成的工具功能修正

### 1. 商城購買後，工具可以真正使用

lib/game/services/tool_manager.dart：

- useServer() 現在取得 PlayerProgressService.instance.activeGameSessionId。
- 呼叫 Firebase useTool 時同時傳 toolType、sessionId。
- 沒有有效 session 時直接拒絕使用。
- 保留 Golden 的 UNDO 無限使用邏輯。

### 2. 測試頁增加「全工具全章節」開關

lib/screens/admin_test_page.dart：

新增 Test Controls：

- Enable all tools in every chapter
- 開啟後：UNDO、REMOVE、SWAP、DUPLICATE 四種工具都可在任何章節使用。
- 關閉後恢復原本章節工具限制。
- 這個功能只屬於測試模式，不改變正式遊戲章節解鎖設計。

### 3. 後端增加測試模式開關

functions/admin_test.js：

新增 adminSetAllToolsEnabled；adminGetTestAccountState 回傳 allToolsEnabledForTest。

只有 Admin 可以替指定測試帳號開關此功能。

### 4. 後端工具使用在測試模式下允許所有工具

functions/index.js：

- getToolInventory 回傳 allToolsEnabledForTest。
- useTool 讀取使用者的測試旗標。
- 測試旗標開啟時，該測試帳號的遊戲 session 允許全部四種工具，不受章節限制。
- 一般帳號仍使用 allowedToolsForChapter(chapterIndex)。

### 5. 遊戲端會動態刷新工具清單

ToolManager.refreshServerState() 與 GameEngine.refreshToolProgress() 已加入測試旗標變更偵測。

- 測試頁開啟全工具後返回遊戲，不必重開 App 才能取得四種工具。
- 關閉測試模式也能恢復章節限制。

### 6. Duplicate 的章節限制加入測試模式例外

GameEngine.useDuplicate()：

- 正式模式：維持原本 History / Technology 限制。
- 全工具測試模式：任何章節都可以使用 DUPLICATE。
