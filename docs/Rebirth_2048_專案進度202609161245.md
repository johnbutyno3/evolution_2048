## 3. 已完成：商城／會員／工具 Server Authority

### 3.1 Membership

- Membership resolution 已集中化。

### 3.2 Tool Inventory

Tool Inventory 已完成 server-authoritative 基礎，不得再視為「尚未建立」。

已存在：
- `getToolInventory`
- `purchaseTool`
- `useTool`
- Chapter reward inventory grant
- server-side tool inventory persistence / transaction handling

Flutter 端：
- `ToolManager` 讀取 server inventory。
- 購買與使用工具走 server callable。
- `ToolsPage` 使用 server inventory。
- `GameEngine` 四種工具操作均走 server `useTool()` 路徑。

工具類型：
- revive
- timeRewind
- positionSwap
- duplicate

### 3.3 Game Session / Replay / Anti-Cheat

- Game session security 規則已建立。
- Replay validation 已納入 chapter tool permission 檢查。
- 受保護資源不得由 client 直接授予。
- Purchase transaction ID 必須具備唯一性／idempotency。
- Production 不得以假付款成功取代真實付款驗證。
- Google Play / Apple 真正付款驗證仍依既定規劃暫緩，待商店帳號與付款驗證資料準備後再接。
