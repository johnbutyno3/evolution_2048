## 本輪修改：帳號切換與延遲回應隔離

### SaveManager 與登入狀態

- 遊戲存檔、Session ID、玩家名稱、玩家 ID、頭像索引使用 UID 專屬本機 key。
- 快照須符合目前帳號及伺服器 Session；舊 Session 棋盤不可恢復為目前棋盤。
- 舊版全域存檔只有在舊 Session ID、章節快照 Session ID 與伺服器權威 Session 完全相符時才遷移；舊 key 保留。
- `SaveManager.bindAccount` 偵測 UID 改變時，清除 Life、Gold、Tool 記憶體快取。
- Firebase Auth 狀態為登出時，主畫面等待解除帳號綁定完成後才顯示登入頁。
- GameEngine / ReplayRecorder 記住建立時的 UID；舊引擎快照不得寫入其他帳號的存檔空間。

### Life / Gold / Tool

- Life 讀取以 generation + UID 防止舊回應覆蓋較新的狀態。
- Life / Gold 套用伺服器狀態的正式呼叫帶入 originating UID。
- Gold 讀取與支出在 callable 回應後再次檢查 UID/generation。
- Tool inventory refresh 與購買加入 UID/generation 檢查；過期購買結果與錯誤不更新新帳號狀態。
- Pending operation 可依原始 UID 清除，避免跨帳號刪除重試記錄。

### Session / 個人資料 / 圖鑑

- start-session 背景工作以開始時捕獲的 UID 執行所有 Session / Life reconciliation。
- abandon-session 回應在寫回章節進度前檢查 UID；帳號切換後丟棄過期回應。
- 個人資料初始化、頭像、名稱更新在寫入本機快取前確認帳號未變。
- 圖鑑讀取與發現生物批次操作會檢查 UID；舊帳號工作在切換後停止。
- AdminService 管理員角色讀取會丟棄帳號切換後的舊結果。
